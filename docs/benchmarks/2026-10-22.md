Time measures a headless solve including initialization and independent result
validation. Peak memory is the maximum traced Python allocation in a separate
replay, not total process RSS. Only matching replays contribute memory values.

Greedy was slightly slower on these maps and retained less traced peak allocation.
DFS keeps recursive generator frames and copied prefix tuples, so its measured
memory can exceed Greedy's on small inputs. This does not change Greedy's
exponential worst-case frontier storage. The dataset is small and easy under
the shared pruning. Add harder and unsolvable inputs before making broad claims.
